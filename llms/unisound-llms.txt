# Unisound

> Unisound (云知声) is a Chinese AGI technology company delivering conversational AI for smart living and smart healthcare. Its Token Hub MaaS platform exposes OpenAI- and Anthropic-compatible APIs for the U2 agent-native LLM family, plus speech recognition, speech synthesis, voice cloning, voiceprint, and OCR document-parsing APIs; the legacy AI Open Platform serves WebSocket speech APIs and the Shanhai (UniGPT) LLM WebAPI.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21 (no provider-published llms.txt was found).

## APIs

- [Token Hub API reference](https://maas.unisound.com/docs/api/overview): Multi-modal MaaS API at https://maas-api.unisound.com/v1 — OpenAI-compatible chat completions, Anthropic-compatible messages (/anthropic/v1/messages), WSS speech recognition, async transcription/synthesis/OCR tasks, voiceprint, voice cloning, file management. Bearer API-key auth.
- [Shanhai (UniGPT) LLM WebAPI](https://ai.unisound.com/doc/unigpt/WebAPI.html): POST https://unigpt-api.hivoice.cn/rest/v1.1/chat/completions with SHA-256 signature auth.
- [AI Open Platform speech WebAPI](https://ai.unisound.com/doc/asronesentence/WebAPI.html): WebSocket one-sentence ASR at wss://ws-osasr.hivoice.cn/v1/asr (dialects host ws-osasr-dialect.hivoice.cn), real-time transcription, oral evaluation, TTS, voiceprint.
